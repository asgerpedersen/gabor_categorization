## Metacognitive awareness of uncertainty-based adjustments of decision boundaries in visual categorization
This repository contains the source code developed for a cognitive psychology paper by Kristoffersen et al. 2025. 
The src directory includes the source code for a trial-to-trial, uncertainty-based decision task, with embedded confidence ratings, developed in PsychoPy and data collected from 16 subjects. 
Analyses directory includes r-script for the analyses conducted on the data.
